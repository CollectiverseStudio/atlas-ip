## Setting Up Your Event

### Step 1: Create Your Event

Go to **collectiverse.com/events/create** (or Events → Host an Event in the app)

#### Required Information

| Field | Tips |
|-------|------|
| **Event name** | Clear and searchable: "DFW Sports Card Show - July 2026" |
| **Date & time** | Include setup time (for vendors) and public hours |
| **Location** | Full address + venue name + room/hall if applicable |
| **Category** | Sports Cards, Comics, TCG, Multi-Category, etc. |
| **Description** | What to expect, who should attend, parking info |
| **Cover image** | 1200×630px — shows in search results and shares |

#### Optional (But Recommended)

| Field | Why It Helps |
|-------|-------------|
| **Vendor count** | "50+ tables" — sets expectations |
| **Admission price** | Free? $5? Early bird? |
| **Special guests** | Signers, graders, breakers — major draws |
| **Event rules** | Bag policy, no outside food, etc. |
| **Parking info** | Saves a ton of questions |
| **Social links** | Your event's Instagram, Facebook group, etc. |

### Step 2: Configure Event Settings

#### Attendance Settings
- **RSVP required?** — Yes (helps predict attendance) / No (open door)
- **Capacity limit** — Set max if venue has limits
- **Early bird window** — Give RSVPs early entry (great incentive)
- **Check-in method** — QR code (recommended) / Manual

#### Vendor Settings
- **Table fees** — Set price per table/booth
- **Application required?** — Yes (curate vendors) / No (first-come)
- **Vendor categories** — What types of vendors you want
- **Setup time** — When vendors can arrive before public hours
- **Table sizes** — Standard, premium, corner, etc.
- **Electricity availability** — If applicable

#### Ticketing (if applicable)
- **Free admission** — QR check-in still tracks attendance
- **Paid admission** — Set price, enable digital tickets
- **Early bird pricing** — Discounted before a date
- **VIP option** — Early entry, exclusive area, etc.
- **Group rates** — Discount for 4+ attendees

### Step 3: Add Vendors

#### Vendor Onboarding Options

**Option A: Invite Specific Vendors**
1. Enter vendor names/emails
2. They receive an invitation with event details
3. They accept, choose table preference, pay fee
4. Confirmed vendors appear on your event page

**Option B: Open Applications**
1. Enable "Apply to Vend" on your event page
2. Vendors fill out application (what they sell, table needs)
3. You review and approve/decline
4. Approved vendors pay and are confirmed

**Option C: Import from Previous Event**
1. Select a past event
2. Re-invite all (or selected) vendors from that event
3. They confirm with one click
4. Pre-populated with their previous setup preferences

#### Vendor Management Dashboard

Your dashboard shows:
- ✅ Confirmed vendors (paid and setup-ready)
- ⏳ Pending (invited but not confirmed)
- 📋 Applications (awaiting your review)
- 💰 Revenue (table fees collected)
- 📍 Floor plan (booth assignments — if configured)
- 📨 Communication (bulk message all vendors)

## QR Check-In System

### How It Works

```
┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│   Attendee   │         │   QR Code    │         │  Organizer   │
│   arrives    │───►     │   at door    │───►     │  dashboard   │
│              │  Scans  │              │ Records │  live count  │
└──────────────┘         └──────────────┘         └──────────────┘
```

### Setup

1. **Generate** your event QR code from the organizer dashboard
2. **Print** the QR code poster (we provide a print-ready PDF)
3. **Display** at each entrance (recommend minimum 2 locations)
4. **Monitor** check-ins in real-time on your dashboard

### QR Code Placement

| Location | Purpose |
|----------|---------|
| **Main entrance** | Primary check-in point |
| **Registration table** | Staff-assisted check-in |
| **Vendor area entrance** | If separate from general admission |
| **Each vendor table** | Vendors can encourage check-in |
| **Restroom area** | Catches people who missed the entrance |

### What Attendees See When They Scan

1. **Welcome screen**: "Welcome to [Event Name]! ✓ Checked in"
2. **Event hub**: Vendor list, floor plan, event schedule
3. **Your inventory**: Browse vendor listings right from their phone
4. **Event chat**: Connect with other attendees in real-time
5. **Trust score**: "+5 points for checking in!" notification

### Check-In Options

| Method | Best For |
|--------|----------|
| **QR scan (self-serve)** | Large events, fast throughput |
| **QR scan (staff-assisted)** | Paid admission, controlled access |
| **Manual check-in** | Small events, personal touch |
| **Pre-check (online)** | RSVP converts to check-in at arrival |

### Live Dashboard (During Event)

Your real-time dashboard shows:
- 📊 **Current attendance count** (live)
- 📈 **Check-in rate** (arrivals per 15-minute block)
- ⏰ **Peak times** (when most people arrive)
- 👤 **Attendee breakdown** (new vs. returning, buyer vs. seller)
- 🔥 **Activity feed** (transactions, follows, messages happening)
- 📍 **Heat map** (if you have multiple QR points, see traffic flow)

## Event Day Checklist

### Pre-Event (Day Before)

```
☐ QR code posters printed and ready
☐ All vendors confirmed and know setup time
☐ Signage prepared (direction signs, rules, schedule)
☐ WiFi tested (or hotspot available)
☐ Dashboard tested (can you see check-ins?)
☐ Staff briefed on check-in process
☐ Push notification scheduled ("See you tomorrow!")
☐ Social media post scheduled ("It's tomorrow!")
```

### Event Morning (Setup)

```
☐ QR codes posted at all entrances
☐ Staff stationed at check-in points (if assisted)
☐ Dashboard open on organizer device
☐ WiFi/connectivity confirmed
☐ Vendors checking in and setting up
☐ Test a check-in scan (verify it works!)
☐ Social media: "Doors open in [X] minutes!"
```

### During Event

```
☐ Monitor dashboard for check-in flow
☐ Walk the floor — capture content for social
☐ Post stories/updates: "250 collectors and counting!"
☐ Handle any vendor issues via dashboard messaging
☐ Announce giveaways/activities (if applicable)
☐ Note observations for post-event improvements
```

### Post-Event (Same Day)

```
☐ Thank-you push notification to attendees
☐ Thank-you message to vendors
☐ Social media recap post
☐ Save any photos/content for future promotion
☐ Note attendance counts while fresh
```

### Post-Event (Within 1 Week)

```
☐ Review full analytics dashboard
☐ Send vendor performance reports
☐ Send attendee survey (optional)
☐ Publish event recap on Collectiverse
☐ Announce next event date (if recurring)
☐ Follow up with potential sponsors (with data)
☐ Export attendee list for future event promotion
```

## Event Series: Building a Recurring Show

### Why Recurring Events Win

- **Attendance compounds** — Each event is bigger than the last
- **Vendor loyalty** — Regulars make planning easier
- **Sponsorship value** — Multi-event packages worth more
- **Community** — Attendees build relationships over time
- **Brand recognition** — "The first Saturday show" becomes a thing

### Setting Up a Series

1. **Create your first event** (follow setup above)
2. **After the event**, mark it as "Part of a series"
3. **Set recurrence** — Monthly, bi-monthly, quarterly
4. **Auto-create** next event (pre-filled from last one)
5. **Attendees auto-follow** your series (notified of each new event)

### Growing Your Series

| Event # | Focus |
|---------|-------|
| 1-3 | Build attendance, recruit vendors, establish rhythm |
| 4-6 | Introduce digital payments, optimize based on data |
| 7-10 | Add sponsorships, premium features, grow revenue |
| 10+ | Scale (bigger venue, more vendors, regional recognition) |
