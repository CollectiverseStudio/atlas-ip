## How the Sync Works

### Technical Overview

```
┌─────────────────────────────────────────────────────────┐
│                    YOUR INVENTORY                         │
├─────────────────────────────────────────────────────────┤
│                                                          │
│   ┌───────────────┐    Real-Time    ┌───────────────┐   │
│   │               │◄──── Sync ─────►│               │   │
│   │  eBay Store   │                 │ Collectiverse │   │
│   │               │                 │    Store      │   │
│   └───────────────┘                 └───────────────┘   │
│                                                          │
│   • List on either → appears on both                     │
│   • Sell on either → inventory updates everywhere        │
│   • Price change → syncs (or keep independent pricing)   │
│   • End listing → ends on both                           │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### What Syncs

| Data Point | Sync Behavior |
|-----------|---------------|
| **Listing title** | Imported from eBay, editable on Collectiverse |
| **Description** | Synced both ways |
| **Photos** | Imported from eBay (add more on Collectiverse) |
| **Price** | Synced by default OR set independently per platform |
| **Quantity** | Always synced (prevents overselling) |
| **Condition** | Mapped to Collectiverse condition grades |
| **Category** | Auto-mapped (review recommended) |
| **Sold items** | Real-time — sell on one, deducts from both |
| **Tracking** | Shared across platforms |

### What Stays Independent

- Collectiverse-specific features (Passport tags, event listings, offers)
- Platform-specific promotions
- Buyer communication (handled per-platform)
- Reviews and ratings (separate systems)

## Migration Guide: From eBay-Only to Multi-Channel

### Phase 1: Connect (5 minutes)

1. **Create Collectiverse account** at collectiverse.com/sell
2. Go to **Store Settings → Integrations → eBay**
3. Click **"Connect eBay Account"**
4. Authorize via eBay OAuth (secure, standard process)
5. Done — your accounts are now linked

### Phase 2: Import (10-30 minutes depending on inventory size)

1. Choose import scope:
   - **All active listings** (recommended for first sync)
   - **Specific categories only**
   - **Items over/under a certain price**
   - **Specific condition types** (graded only, raw only, etc.)

2. Review category mapping:
   - Our system auto-maps most eBay categories
   - Review and correct any yellow-flagged items
   - Set default mappings for future listings

3. Review pricing:
   - **Mirror pricing** — Same price on both platforms
   - **Adjusted pricing** — Set a % markup/discount for Collectiverse
   - **Independent** — Manually set different prices per platform

4. Click **"Import & Publish"**

### Phase 3: Optimize (First Week)

- ✅ Complete your Collectiverse store profile (logo, banner, description)
- ✅ Complete your Passport (trust score matters)
- ✅ Review imported listings — add Collectiverse-specific keywords
- ✅ Enable "Make Offer" on appropriate items
- ✅ Share your Collectiverse store on social media
- ✅ Connect payment methods (multiple options = more sales)

### Phase 4: Grow (Ongoing)

- List new items from Collectiverse (syncs to eBay automatically)
- Participate in events and community features
- Build your follower base
- Use analytics to optimize pricing across platforms
- Consider Collectiverse-exclusive drops to build your following

## Frequently Asked Questions

### Setup & Technical

**Q: Will connecting affect my eBay store or listings?**
A: No. Connecting simply reads your eBay data. We never modify your eBay listings unless you explicitly push a change from Collectiverse.

**Q: What about eBay's "off-platform" policies?**
A: Syncing inventory across platforms is standard multi-channel retail — it's fully compliant with eBay policies. Many sellers list on multiple platforms simultaneously.

**Q: What if an item sells on both platforms at the same time?**
A: Our sync is real-time (under 30 seconds). In the extremely rare case of simultaneous sales, inventory conflict resolution kicks in and we'll alert you immediately.

**Q: Do I need to change my eBay workflow?**
A: Not at all. Continue listing, selling, and shipping on eBay exactly as you do now. Collectiverse runs alongside it.

### Pricing & Fees

**Q: What does Collectiverse charge?**
A: Competitive marketplace fees lower than eBay's final value fee. No listing fees for your first 100 items. Full fee schedule at collectiverse.com/fees.

**Q: Can I price differently on each platform?**
A: Yes! Set independent pricing, mirror pricing, or use percentage-based adjustments. You're in control.

**Q: Do I pay fees on both platforms when an item sells?**
A: You only pay fees on the platform where the sale happens. Item sells on eBay = eBay fees. Item sells on Collectiverse = Collectiverse fees.

### Getting Started

**Q: How long does the initial import take?**
A: Most sellers are fully imported in under 30 minutes (including review). Stores with 10,000+ items may take up to an hour.

**Q: Can I import just some of my eBay listings?**
A: Absolutely. Filter by category, price range, condition, or manually select specific items.

**Q: What if I want to remove Collectiverse later?**
A: Disconnect anytime. Your eBay store is completely unaffected. No lock-in, no penalties.
