## Technical SEO Checklist

### Site Architecture

- [ ] **URL Structure:** collectiverse.studio/[category]/[type]/[item-slug]
- [ ] **Breadcrumbs:** Home > Category > Subcategory > Item (with schema)
- [ ] **Internal linking:** Every page links to 3-5 related pages
- [ ] **Flat architecture:** No page more than 3 clicks from home
- [ ] **Pagination:** rel=next/prev on paginated content
- [ ] **Canonical URLs:** Set on all pages, especially filtered views
- [ ] **Hreflang:** Prepare for international (en-us, en-gb, en-ca, en-au)

### Page Speed & Core Web Vitals

- [ ] **LCP (Largest Contentful Paint):** < 2.5s
  - Optimize hero images (WebP, lazy loading)
  - Preload critical fonts
  - Server-side rendering for above-fold content
- [ ] **FID/INP (Interaction to Next Paint):** < 200ms
  - Defer non-critical JavaScript
  - Code-split heavy components
  - Use React.lazy for below-fold features
- [ ] **CLS (Cumulative Layout Shift):** < 0.1
  - Set explicit dimensions on all images
  - Reserve space for dynamic content

5. Internal link from programmatic pages to editorial content
6. Include structured data on every page
