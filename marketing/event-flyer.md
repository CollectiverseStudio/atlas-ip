# Event Flyer — Design Specs & Copy

**Format:** 8.5" × 11" (Letter) — Print Flyer/Poster  
**Distribution:** Card shows, comic cons, flea markets, hobby shops, LCS bulletin boards  
**Print Method:** Full color, double-sided (front = marketing, back = feature details + QR)  

---

## PRINT SPECIFICATIONS

| Spec | Value |
|------|-------|
| Final Trim Size | 8.5" × 11" (216mm × 279mm) |
| Bleed | 0.125" (3mm) all sides |
| Safe Zone (margins) | 0.25" (6mm) from trim on all sides |
| Resolution | 300 DPI minimum |
| Color Mode | CMYK |
| File Format | PDF/X-1a or PDF/X-4 |
| Paper Stock (recommended) | 100lb gloss text or 80lb gloss cover |
| Coating | UV spot gloss on Atlas mascot + logo (optional premium) |

## DESIGN NOTES

1. **Background:** Front uses navy-to-blue gradient. Back uses clean white with blue accents.
2. **Typography:** Maximum 2 font families (suggest Montserrat for headlines, Inter for body). No more than 3 weights per family.
3. **White space:** Don't overcrowd — let the design breathe, especially on the back.
4. **QR Codes:** Test at actual print size before finalizing. Ensure sufficient quiet zone (white border).
5. **Atlas mascot:** Use high-res vector or 600+ DPI raster. Character should feel alive and approachable.
6. **Bleed elements:** Background gradient and any edge-touching graphics must extend to bleed line.
7. **Proofing:** Print a test copy on actual stock at actual size. Check QR scans from arm's length.
