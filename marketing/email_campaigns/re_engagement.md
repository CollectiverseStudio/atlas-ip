## Sequence Strategy & Implementation Notes

### Sequence Flow:

```
Day 0: Last activity
   │
Day 30: Email 1 — "We miss you" (warm, informational)
   │
   ├── User returns → Exit sequence, trigger "Welcome back!" moment
   │
Day 45: Email 2 — "What's new" (value-focused, tour of improvements)
   │
   ├── User returns → Exit sequence
   │
Day 60: Email 3 — "Special offer" (incentive to return)
   │
   ├── User returns → Exit sequence, apply offer
   │
Day 90: Email 4 — "Last chance" (transparency about changes)
   │
   ├── User returns → Exit sequence, cancel changes
   │
Day 90+: No more marketing emails. Account enters dormant state.
```

### Key Principles:

1. **Never guilt-trip.** The tone is always "we're here when you're ready"
2. **Provide genuine value** — Show what they're missing, not what they owe
3. **Respect the decision** — Make it easy to leave cleanly
4. **Be transparent** — Explain exactly what happens and why
5. **Make return effortless** — One click should fully reactivate
6. **Escalate incentive, not pressure** — Each email offers more value, never more guilt

### Segmentation Variants:

| Segment | Adjustments |
|---------|-------------|
| **Free users, never activated** | Skip Email 3 offer, focus on "getting started" value |
| **Free users, previously active** | Standard sequence |
| **Pro users, subscription active** | Mention they're paying for unused features |
| **Pro users, subscription lapsed** | Offer discounted return rate |
| **High-value collectors (100+ items)** | Emphasize collection value changes prominently |
| **Marketplace sellers** | Mention missed sales opportunities, buyer messages |
| **Community-active users** | Emphasize events, community, what friends are doing |

### Exclusions:
- Do NOT send re-engagement emails to users who opted out of marketing
- Do NOT send if user has contacted support (route to support follow-up instead)
- Do NOT send if user explicitly said they're leaving (respect the decision)
- Pause sequence if user opens/clicks but doesn't log in (adjust timing)

### Success Metrics:

| Email | Target Re-activation Rate |
|-------|--------------------------|
| Email 1 (30 days) | 15-20% |
| Email 2 (45 days) | 10-12% |
| Email 3 (60 days) | 8-10% |
| Email 4 (90 days) | 3-5% |
| **Total sequence recovery** | **30-40%** |

### Post-Return Experience:
- Show "Welcome back!" modal with personal collection summary
- Highlight what changed since they left (personalized changelog)
- If they claimed an offer, apply it immediately
- Reset inactivity timer
- Add to "returned user" segment for monitoring (watch for second churn)
