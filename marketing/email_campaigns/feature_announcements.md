## Template Usage Notes

### When to Use Each Template:
- **Major launches** (Atlas AI, Mobile App): Send to entire user base + waitlist
- **Feature additions** (Smart Capture, Price Intelligence): Send to active users + segment by relevance
- **Premium features** (Blockchain, Estate Planning): Target Pro users + high-value free users for upgrade nudge
- **Platform features** (Events PWA, Live Selling): Target active community members

### Customization Points:
- Personalize based on user's collecting categories
- Reference their collection size / recent activity
- Adjust free vs. Pro messaging based on current plan
- Include relevant examples for their specific collecting niche

### A/B Testing Suggestions:
- Test emoji vs. no emoji in subject lines
- Test feature-first vs. benefit-first body copy
- Test short (one-screen) vs. detailed (scroll) formats
- Test single CTA vs. multiple CTAs
