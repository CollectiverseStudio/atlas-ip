# ATLAS LICENSEE USAGE GUIDE

## Version

1.0

## Purpose

This guide defines how approved partners, contractors, vendors, licensees, and manufacturers may use Atlas.

This is not a complete legal contract. It is an operational usage guide that should be attached to or referenced by written agreements.

---

## Ownership

Atlas is owned by Collectiverse Studio / Gregory Bell.

No licensee receives ownership of Atlas, Atlas artwork, Atlas character design, Atlas production standards, Atlas prompts, Atlas model sheets, Atlas trademarks, or Collectiverse brand assets unless a separate written agreement expressly says so.

---

## Permitted Uses

A licensee may use Atlas only for the specific purpose approved in writing.

Examples of permitted uses when approved:

- Marketing campaign artwork
- Social media assets
- Educational collectible content
- App interface assets
- Event signage
- Merchandise prototypes
- Product packaging
- Animation clips
- Comic panels
- Licensed physical goods

---

## Prohibited Uses

Atlas may not be used for:

- Political messaging
- Hateful, discriminatory, or offensive content
- Adult content
- Gambling promotions without written approval
- Weapon-related promotion
- Tobacco, vaping, recreational drug, or controlled substance promotion
- Misleading financial claims
- Fake authentication claims
- Counterfeit collectible promotion
- Third-party mascot mashups
- Any use implying ownership by another company
- Any use that damages Collectiverse Studio reputation

---

## Design Compliance

Every licensed use must follow:

- Character Specification
- Brand Bible
- Animation Bible, if animated
- AI Style Governance, if AI-assisted
- Any approved model sheets or reference images

Licensees may not redesign Atlas.

---

## Required Brand Treatment

Unless waived in writing, Atlas should appear with clear Collectiverse association.

Acceptable identifiers:

- Collectiverse name
- Collectiverse logo
- Collectiverse tagline
- Collectiverse app or website context
- Atlas described as the Collectiverse collecting guide

Atlas should not be presented as a generic robot, stock mascot, or licensee-owned character.

---

## Merchandise Standards

Physical merchandise must preserve:

- Helmet shape
- Centered gold star
- Black visor
- Green crescent eyes
- White and metallic blue palette
- Friendly proportions
- Chest emblem when visible
- Safe, family-friendly expression

Manufacturers must submit samples or mockups before production.

---

## AI-Assisted Production

If a licensee uses AI to create Atlas assets, they must:

- Use approved prompt language
- Use approved reference materials
- Avoid third-party character references
- Submit final outputs for review
- Disclose the tool used when requested
- Retain final prompts when practical

AI output is not automatically approved.

---

## Approval Rights

Collectiverse Studio may reject any use that:

- Deviates from canon
- Creates similarity risk
- Weakens Atlas recognition
- Misrepresents Collectiverse
- Uses poor-quality artwork
- Places Atlas in inappropriate context
- Omits required branding

---

## Attribution

When attribution is required, use:

```text
Atlas and Collectiverse are intellectual property of Collectiverse Studio.
```

Do not alter attribution wording without approval.

---

## File Delivery Standards

Final deliverables should include, when applicable:

- PNG exports with transparent background
- WebP exports for web use
- SVG/vector files when created
- Source files when contractually required
- Prompt records for AI-assisted work
- Usage notes
- Color references
- Print specifications for merchandise

---

## Quality Bar

Atlas assets should appear premium, clean, consistent, and trustworthy.

Reject assets that are:

- Blurry
- Off-model
- Poorly lit
- Overly busy
- Inconsistent with color palette
- Similar to another character
- Missing protected elements
- Unfriendly, aggressive, or confusing

---

## Enforcement

Unauthorized use, misuse, redesign, redistribution, or sublicensing may result in takedown requests, termination of permission, refusal of future license, or other enforcement actions.

---

## Practical Rule

A licensee may use Atlas only as approved. When in doubt, ask before publishing, manufacturing, distributing, or selling.
