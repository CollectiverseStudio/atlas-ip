# Legacy Villain Bible Status

The file `canon/character-bible/08-villains.md` is retained as a historical franchise document but is **not authoritative for the current villain roster** where it conflicts with `canon/CURRENT-CHARACTER-ROSTER.md`.

Known legacy conflicts include:
- The Broker is presented as active; it is now archived/deprecated.
- The Archivist is presented as Echo's mirror; The Vault is the current Echo mirror.
- Several species, colors, sizes, and design details predate later character lock-ins.
- The current active villain roster is Director, Counterfeiter, Restorer, Hacker, Hoarder, Vault, Whisper, and Smuggler.

Use current character-specific lock documents and `CURRENT-CHARACTER-ROSTER.md` for production. Preserve the legacy bible for provenance and story-development history.
