# WORLD LOCATIONS

## The Atlas Universe — Setting Bible
### Version 1.0 | Collectiverse Franchise Character Bible

---

# Overview

The Atlas Universe contains nine primary locations, each serving a specific narrative and functional purpose. Every location has a designated "home" Keeper, a visual identity, an emotional tone, and story potential.

**Design Philosophy:** Locations should feel like places the audience wants to visit. They should be visually distinct from each other (identifiable by color palette alone), internally consistent, and rich enough to support multiple stories within the same space.

**Tone Rule:** No location should feel threatening or unwelcoming — even the Shadow Registry should feel "clever-dangerous" rather than "scary." The exception is deliberate tension scenes where a location feels temporarily unsafe (resolved within the scene).

# THE VAULT (Keepers HQ)

## The Heart of Operations

| Attribute | Value |
|-----------|-------|
| **Primary Keeper** | All (shared headquarters) |
| **Security Lead** | Porter |
| **Color Palette** | Clean white, Guardian Blue, silver, soft green lighting |
| **Emotional Tone** | Safe, inspiring, welcoming, professional |
| **Analogues** | Apple Store + Smithsonian + NASA Mission Control |

### Description

The Vault is home. It's where the Keepers begin every mission, where they return after every adventure, and where the most endangered collectibles in the universe are protected. The architecture combines the clean lines of modern technology with the warmth of a world-class museum.

### Key Areas Within The Vault

- **Command Center** — Central holographic table showing active threats and missions
- **Briefing Room** — Where Atlas addresses the team before deployments
- **Secure Storage** — Climate-controlled vaults for endangered collectibles (Porter's domain)
- **Training Ground** — Where new collectors learn basics in a safe environment
- **Living Quarters** — Each Keeper has a personalized space reflecting their specialty
- **Workshop Access** — Direct passage to Forge's workshop

### Visual Details

- High ceilings with holographic skylights showing data streams
- White walls with blue-accented technology panels
- Floating holographic displays showing collection data
- Clean, organized, never cluttered
- Warm lighting despite the technology (never cold/sterile)
- Green ambient indicators showing "all systems safe"

### Story Potential

- Home base scenes (planning, debriefing, character interaction)
- Security breach stories (the Vault is attacked)
- New collector arrival stories (first visit to HQ)
- Character development moments (personal spaces)
- Technology demonstration scenes

# THE ARCHIVE (Echo's Domain)

## The Infinite Library of Memory

| Attribute | Value |
|-----------|-------|
| **Primary Keeper** | Echo |
| **Color Palette** | Deep violet, soft purple glow, translucent crystals, dark wood tones |
| **Emotional Tone** | Reverent, quiet, awe-inspiring, ancient-yet-futuristic |
| **Analogues** | Library of Alexandria + holographic museum + cathedral |

### Description

The Archive is impossible in the best way. It extends infinitely in every direction — towering shelves filled not with books but with glowing memory crystals, each one containing the complete provenance and story of a collectible. Violet light permeates everything. Holographic timelines float between the stacks like fireflies. It feels ancient and futuristic simultaneously — as if time itself is irrelevant here.

### Key Areas Within The Archive

- **The Stacks** — Infinite shelving of memory crystals organized by era and category
- **The Reading Chamber** — Where crystals are activated and stories are projected
- **The Timeline Gallery** — Holographic walkway showing the history of collecting
- **The Lost Section** — Area where broken/incomplete provenance records are stored (always growing smaller as Echo works)
- **Echo's Alcove** — Personal study space where Echo contemplates and researches

### Visual Details

- Towering shelves that disappear into soft violet mist above
- Memory crystals glowing in different intensities (active stories brighter)
- Floating holographic timelines connecting crystals
- Soft ambient sound (whispers of stories, never words)
- No harsh lighting — everything bathed in warm violet glow
- Ancient-looking structural elements (carved wood, stone) combined with holographic tech

### Story Potential

- Research/discovery episodes (finding lost provenance)
- Mystery stories (following a timeline to discover truth)
- Villain intrusion (the Archivist trying to steal records)
- Character reflection moments (any Keeper visiting for perspective)
- Educational sequences (history of collecting categories)

# THE FORGE (Forge's Workshop)

## The Inventor's Paradise

| Attribute | Value |
|-----------|-------|
| **Primary Keeper** | Forge |
| **Color Palette** | Warm copper, orange glow, holographic blue blueprints, industrial white |
| **Emotional Tone** | Creative, energetic, optimistic, slightly chaotic |
| **Analogues** | Tony Stark's workshop + maker space + inventor's garage |

### Description

The Forge is where problems become solutions. It's a sprawling workshop filled with holographic blueprints floating mid-air, robotic assembly arms building prototypes, workbenches covered in components, and the warm copper glow of active manufacturing. It's organized chaos — every surface holds potential, every tool has purpose.

### Key Areas Within The Forge

- **Main Workbench** — Central build station with holographic blueprint display
- **Testing Bay** — Where prototypes are evaluated and stress-tested
- **Material Library** — Wall of components, materials, and raw resources
- **Assembly Floor** — Robotic arms and automated manufacturing
- **Prototype Graveyard** — Shelf of failed attempts (Forge keeps them all — they teach)
- **Blueprint Wall** — Floor-to-ceiling holographic display of current projects

### Visual Details

- Warm copper ambient lighting mixed with blue holographic projections
- Sparks (safe, contained) from active manufacturing
- Components in various states of assembly on every surface
- Robotic arms moving in background (always building something)
- Holographic blueprints that can be grabbed and manipulated
- Satisfying mechanical sounds (clicks, whirs, hums)

### Story Potential

- "Building the solution" montages
- Prototype testing (comedy potential with failures)
- Forge teaching others to build
- Villain sabotage of workshop
- New tool revelation scenes

# THE MARKETPLACE (The Bazaar)

## The Living Commerce Hub

| Attribute | Value |
|-----------|-------|
| **Primary Keeper** | None (neutral territory — all Keepers patrol) |
| **Color Palette** | Vibrant multi-color, warm lighting, golden ambient, diverse textures |
| **Emotional Tone** | Exciting, vibrant, slightly unpredictable, treasure-hunt energy |
| **Analogues** | Grand Bazaar + eBay made physical + card show + flea market |

### Description

The Marketplace is where collectibles change hands. It's bustling, colorful, diverse — stalls and booths displaying everything from vintage comics to ancient coins, modern cards to rare toys. Honest dealers and shady operators coexist in a vibrant ecosystem of commerce. This is where the Keepers' vigilance is most needed — and where collectors need the most guidance.

### Key Areas Within The Marketplace

- **Main Floor** — Open trading area with stalls and booths
- **Auction House** — Formal space for high-value sales
- **Trading Pit** — Where collectors meet to exchange items directly
- **Information Desk** — Keeper-staffed guidance station
- **Dark Corners** — Shadowy areas where less legitimate activity occurs
- **Authentication Station** — Where items can be verified before purchase

### Visual Details

- Colorful stalls with diverse collectible categories
- Crowd energy (diverse collectors of all types)
- Holographic price displays and item showcases
- Mix of old-world market aesthetics and modern tech
- Occasional suspicious characters in peripheral vision
- Warm golden ambient lighting with colorful booth accents

### Story Potential

- Buying/selling stories
- Scam detection plots
- Rare find discoveries
- Community interaction scenes
- Villain operations exposure
- Commerce education episodes

# THE SHADOW REGISTRY (Villain HQ)

## The Dark Mirror

| Attribute | Value |
|-----------|-------|
| **Primary Villain** | The Director |
| **Color Palette** | Dark charcoal, deep crimson, glitch effects, corrupted data |
| **Emotional Tone** | Uneasy, clever, sophisticated, digital noir |
| **Analogues** | Dark web visualization + corrupted Archive + villain lair |

### Description

The Shadow Registry is the decentralized villain network — a dark counterpart to The Archive. Where The Archive preserves truth, the Shadow Registry manufactures lies. Forged provenance records, stolen data, manipulation schemes — all coordinated through this glitchy, corrupted digital space.

### Visual Details

- Same architectural language as Keeper locations but corrupted
- Data streams that flicker and glitch
- Red/black replacing blue/white
- Information floating as broken, fragmented holograms
- No clear center (decentralized — multiple access points)
- Slightly unsettling visual distortion (not scary — uneasy)

### Story Potential

- Villain planning scenes
- Infiltration missions (Keepers sneaking in)
- Data theft discoveries
- The Director's schemes revealed
- Evidence gathering for community exposure

# Location Design Rules

1. **Color-Coded:** Each location identifiable by dominant color palette alone
2. **Character-Linked:** Each location reflects its Keeper's personality
3. **Internally Consistent:** Physics and aesthetics don't change between visits
4. **Story-Rich:** Each location can support multiple unique stories
5. **Visually Distinct in Silhouette:** Architectural shapes are unique per location
6. **Welcoming:** Even the villain location is "interesting" not "scary"
7. **Scalable:** Locations can be shown in wide establishing shots or tight detail shots
8. **Connected:** All locations exist in the same universe with logical travel between them
