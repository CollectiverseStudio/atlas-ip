# Shared Visual Language

## The Keeper Design System

All Keepers share a unified design language that immediately communicates "same team, same universe" while allowing individual personality to shine through.

### Universal Keeper Elements

| Element | Standard |
|---------|----------|
| **Base Armor Color** | White (gloss painted composite) |
| **Accent System** | Individual color applied to: shoulder panels, boot trim, helmet details, badge |
| **Head-to-Body Ratio** | Head 45%, Body 55% (consistent across all Keepers) |
| **Material Language** | Gloss white composite, painted metal, rubberized joints |
| **Visor Type** | Black gloss glass (individual modifications per character) |
| **Chest Badge** | Graphite hexagon with individual icon in accent color |
| **Joint Material** | Black segmented mechanical (universal) |
| **Hand Construction** | Black segmented, 5 fingers, rounded fingertips (universal) |
| **Boot Style** | Sneaker-inspired, white base, accent trim (universal) |
| **Overall Style** | Pixar-quality, rounded, friendly, premium, toy-like |

# Silhouette Recognition

## The Thumbnail Test

Every character must be instantly recognizable as a pure black silhouette at 64x64 pixels. This ensures recognition across all media sizes — from feature film to app icon.

### Silhouette Differentiators

| Character | Silhouette Key Feature |
|-----------|----------------------|
| **Atlas** | Standard proportions + gold star on helmet (round, balanced) |
| **Pixel** | Slightly smaller + antenna nub + lean forward posture |
| **Ink** | Taller, thinner + flowing movement suggestion + journal |
| **Sterling** | Stockier + monocle loupe attachment + planted stance |
| **Forge** | Broader shoulders + tool belt + multi-tool arm suggestion |
| **Porter** | Largest overall + shield chest plate + wide protective stance |
| **Echo** | Standard height but ethereal + ambient particle aura |

### Silhouette Rule

If you cannot identify which Keeper is which in pure silhouette, the character designs need adjustment. Individuality must survive the loss of all color and detail information.

# Pixar's 12 Principles Applied to Each Character

## 1. Squash & Stretch

| Character | Application |
|-----------|-------------|
| Atlas | Moderate — visible bounce in excitement, subtle in calm |
| Pixel | High — springy, reactive, more cartoon elasticity |
| Ink | Low — flowing stretch on movements, minimal squash |
| Sterling | Minimal — rigid, precise, very little distortion |
| Forge | Moderate — hammer-strike emphasis, building energy |
| Porter | Low — solid, weighty, minimal compression |
| Echo | Subtle — ethereal stretch, ghost-like fluidity |

## 2. Anticipation

| Character | Application |
|-----------|-------------|
| Atlas | Clear anticipation before jumps, gestures, turns |
| Pixel | Very short anticipation (impatient — loads fast, fires faster) |
| Ink | Long, graceful anticipation (builds slowly, releases fluidly) |
| Sterling | Precise anticipation (exact timing, never early, never late) |
| Forge | Strong anticipation for physical actions (winding up before building) |
| Porter | Heavy anticipation for protective moves (deliberate preparation) |
| Echo | Minimal visible anticipation (movements seem to emerge naturally) |

## 3. Staging

All characters follow the same staging principles:
- Clear silhouette in every pose
- Key expression readable from any angle
- Never two characters performing competing actions simultaneously
- Focus character always has clearest staging in frame

## 4. Timing

| Character | Timing Profile |
|-----------|---------------|
| Atlas | Medium — standard heroic timing, slightly quick |
| Pixel | Fast — everything happens quickly, snappy |
| Ink | Slow — graceful, unhurried, deliberate |
| Sterling | Precise — metronome-like consistency |
| Forge | Variable — slow build to fast execution |
| Porter | Slow — heavy, deliberate, powerful |
| Echo | Ethereal — seems to exist outside normal time |

# Interaction Rules

## Formation & Hierarchy

When all Keepers are together:

**Standard Formation (facing camera):**
```
        [Echo]
    [Ink]   [Sterling]
  [Pixel] [Atlas] [Forge]
        [Porter]
```

Atlas is always center. Porter anchors the rear (protective). Echo elevated (wisdom). Wings arranged by energy (high-energy Pixel and Forge flanking Atlas; contemplative Ink and Sterling in middle tier).

**Walking Formation:**
```
Direction of travel →

[Pixel]──[Atlas]──[Forge]
    [Ink]──[Sterling]
         [Porter]
              [Echo]
```

Pixel leads (eager), Atlas directs, Forge alongside. Ink and Sterling middle. Porter rear guard. Echo trailing (contemplative, slightly apart).

## Interaction Spacing

- Characters never overlap unless intentionally interacting
- Personal space: Minimum 1 body-width between characters in neutral scenes
- Close interaction: Characters may close to 0.5 body-width for teamwork/friendship moments
- Never crowd — even group shots maintain readable spacing

# Villain Visual Language

## Corruption System

Villains use the same design language as Keepers but with systematic corruption:

| Keeper Standard | Villain Corruption |
|---|---|
| White armor | Dark charcoal / black |
| Individual accent color | Darker/sharper version of their own accent |
| Soft glow effects | Harsh, pulsing, or glitching effects |
| Green/colored eyes | Red, yellow, or villain-accent-matched |
| Gold star (Atlas) | Absent / broken / tarnished |
| Rounded edges | Slightly sharper (within rounded aesthetic — never spiky) |
| Clean surfaces | Subtle texture corruption (glitch, tarnish, or distortion) |
| Warm ambient lighting | Cool/harsh lighting (but never horror) |
| Hexagon badge | Same shape, villain icon |
| White background default | Dark/colored background |

## Villain-Specific Visual Rules

- **Same art style** as Keepers — not a different visual universe
- **Same proportional system** (big head, compact body, rounded overall)
- **Recognizably corrupted** — audience should see "that's a broken Keeper, not a different species"
- **Never genuinely frightening** — clever, formidable, interesting to look at
- **Individual silhouette recognition** — as distinct from each other as Keepers are

# Camera Rules for Ensemble Shots

## Standard Camera Positions

| Shot Type | Use | Lens | Notes |
|-----------|-----|------|-------|
| **Wide Ensemble** | Team establishing shots | 35mm | All characters visible, clear hierarchy |
| **Hero Medium** | Atlas leading/speaking | 50mm | Atlas centered, others visible peripherally |
| **Duo Shot** | Two-character interaction | 50mm | Both characters equally framed |
| **Over-Shoulder** | Conversation coverage | 65mm | One character's perspective of another |
| **Group Action** | Team working together | 28mm | Wider angle captures action without distortion |
| **Villain Reveal** | Antagonist introduction | 35mm | Low angle (slight), dramatic staging |

## Camera Rules

- **Never shoot a Keeper from below in threatening way** (low angles reserved for "inspiring" not "intimidating")
- **Villain reveals may use slight low angle** (establishes formidable presence without horror)
- **Never dutch angle** (tilted camera) for Keepers
- **Never handheld shake** for normal scenes (stability = trust)
- **Slow dolly preferred** for emotional moments
- **Quick cuts allowed** for Pixel-centric action scenes only
- **Arc/orbit** for revelation moments

## Group Shot Composition Rules

1. Atlas always readable (never obscured by another character)
2. Height variation creates natural visual interest
3. Active character has most open staging
4. Porter always positioned to suggest protection of others
5. Echo slightly separated (wisdom/observation position)
6. Pixel often at edge of frame (about to move toward something)
7. Never all characters performing the same action simultaneously (unless deliberate for comedy)

# Rendering Standards (Technical)

## Universal Render Settings

| Parameter | Value |
|-----------|-------|
| **Rendering Method** | Physically Based Rendering (PBR) |
| **Illumination** | Global Illumination, ray-traced reflections |
| **Shadows** | Soft ambient occlusion, subtle cast shadows |
| **Effects** | Subtle bloom, volumetric lighting (soft) |
| **Depth of Field** | Cinematic (subject always sharp) |
| **Resolution** | Minimum 4K for master renders |
| **Frame Rate** | 24fps (cinematic), 30fps (social content) |
| **Anti-Aliasing** | Maximum quality |
| **Background Default** | Pure white unless scene requires environment |

## Lighting Standards

- **Bright studio lighting** — primary light at 45° above and 30° to side
- **Neutral white balance** — never colored unless environmental (sunset, etc.)
- **Soft shadows** — never harsh or dramatic for Keepers
- **No horror lighting** — never from below, never flickering for Keepers
- **Villain scenes** may use slightly cooler, directional lighting (never scary)
- **Atlas should always look clean** regardless of scene lighting

## Material Rendering Priorities

1. Helmet glossy reflections must read clearly
2. Visor must show realistic glass-like reflection
3. Eyes must glow softly (bloom effect)
4. Metal accents must show environmental reflections
5. Joint segments must read as separate pieces
6. Surface quality must communicate "premium toy"
