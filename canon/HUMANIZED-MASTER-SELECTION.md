# Humanized Master Selection Record

**Decision date:** 2026-09-21

## User-authorized rule

Use the **latest approved humanized image for each character** as the canonical humanized master.

## Source precedence

1. Existing explicitly approved standalone humanized master/pose image.
2. Latest approved consolidated character roster showing the locked humanized design.
3. Earlier character-card/dossier material only as supporting reference, not as a replacement for a later consolidated design.

## Applied state

- Ink: existing approved humanized pose/master retained.
- Sterling: existing approved manually developed humanized pose/master retained.
- Atlas, Pixel, Forge, Porter, Echo, Director, Counterfeiter, Restorer, Hacker, Hoarder, Vault, Whisper, Smuggler: master extraction is derived from the latest consolidated approved roster representation so all 15 characters have a deterministic canonical identity reference.

## Safety

The roster-derived master is an identity anchor, not a claim that the crop itself is the highest-resolution production artwork. If a later exact standalone approved master is recovered, it may replace the crop without changing the approved character design.

Pose generation remains reference-conditioned and QA-gated.
