### Typography Rules
- Monospace for all timestamps/durations
- Bold for camera directions (technical crew reads these fast)
- Italic for audio and director notes (secondary info)
- Action descriptions: imperative voice ("Atlas picks up card", not "Atlas is picking up")
- Maximum 2 lines per text field in each panel

## ✅ Required Elements

1. **6 numbered panels** — Sequential, left-to-right, top-to-bottom
2. **Scene frame** — 16:9 illustration/sketch in each panel
3. **Panel numbers** — Bold, colored, clearly sequential
4. **Duration markers** — Start and end timestamp for each panel
5. **Camera direction** — Shot type for each frame
6. **Action description** — What happens in the scene
7. **Timeline bar** — Visual duration representation at bottom
8. **Header info** — Project name, scene number, page number, date

## 📷 Camera Direction Reference

### Standard Shot Types
| Code | Full Name | Description | When to Use |
|------|-----------|-------------|-------------|
| `EWS` | Extreme Wide Shot | Full environment, tiny character | Establishing/location |
| `WS` | Wide Shot | Full body + environment | Scene setting |
| `MWS` | Medium Wide Shot | Knees up + context | Walking/movement |
| `MS` | Medium Shot | Waist up | Dialogue/interaction |
| `MCU` | Medium Close-Up | Chest up | Emotional moment |
| `CU` | Close-Up | Head/face | Reaction/expression |
| `ECU` | Extreme Close-Up | Eyes/detail only | Dramatic emphasis |
| `OTS` | Over the Shoulder | From behind one character | Conversation |
| `POV` | Point of View | Character's viewpoint | Immersion |
| `2S` | Two-Shot | Two characters framed | Relationship |
| `HA` | High Angle | Camera looking down | Vulnerability |
| `LA` | Low Angle | Camera looking up | Power/heroic |
| `DUTCH` | Dutch Angle | Tilted horizon | Tension/unease |

### Camera Movements
| Code | Movement | Use |
|------|----------|-----|
| `PAN L/R` | Horizontal rotation | Reveal/follow |
| `TILT U/D` | Vertical rotation | Reveal height |
| `DOLLY IN/OUT` | Move toward/away | Focus/reveal |
| `TRUCK L/R` | Move laterally | Follow alongside |
| `CRANE UP/DOWN` | Move vertically | Epic reveal |
| `ZOOM IN/OUT` | Lens zoom | Emphasis |
| `STATIC` | No movement | Stability/pause |
| `SHAKE` | Handheld feel | Energy/chaos |
| `RACK FOCUS` | Shift focus depth | Redirect attention |

## ✔️ Do's

- ✅ Number every panel sequentially across ALL pages (Panel 7 starts page 2)
- ✅ Include transition type between every panel (even if just "CUT")
- ✅ Write action descriptions in present tense, imperative voice
- ✅ Vary shot types — avoid 3+ identical camera angles in a row
- ✅ Mark "KEY FRAME" on panels that need detailed illustration
- ✅ Include Atlas's expression note for animators (e.g., "determined → surprised")
- ✅ Align timeline bar proportionally to actual duration
- ✅ Note any required props/collectibles per scene
- ✅ Include audio direction even in silent moments ("SILENCE" or "AMB: room tone")
- ✅ Reference Atlas model sheet for pose/expression consistency

---

## ❌ Don'ts

- ❌ Don't skip panel numbers (even for time jumps — note "TIME CUT" instead)
- ❌ Don't write more than 3 lines in any description field
- ❌ Don't use vague camera directions ("somewhere around medium shot")
- ❌ Don't forget the timeline bar — it's essential for pacing review
- ❌ Don't mix 16:9 and 9:16 frames on the same page without marking clearly
- ❌ Don't leave any panel without a duration (even estimated)
- ❌ Don't use color coding inconsistently between pages
- ❌ Don't include final dialogue — that belongs in the script (storyboard = visual)

## 🎬 Transition Reference

| Symbol | Type | Visual | Duration |
|--------|------|--------|----------|
| `→` | Hard Cut | Instant | 0 frames |
| `⟶` | Dissolve | Cross-fade | 12-24 frames |
| `▸▸` | Fade to Black | Through black | 12 frames |
| `◀▸` | Fade from Black | From black | 12 frames |
| `⟿` | Wipe | Directional reveal | 6-12 frames |
| `↺` | Whip Pan | Fast blur pan | 6-8 frames |
| `⊕` | Iris | Circle open/close | 12 frames |
| `⚡` | Smash Cut | Jarring instant cut | 0 frames |
| `♪→` | Sound Bridge | Audio carries over cut | Varies |
