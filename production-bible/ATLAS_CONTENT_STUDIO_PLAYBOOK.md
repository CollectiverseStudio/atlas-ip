# Purpose

This document defines the complete workflow for creating Atlas content.

Every comic, short, video, advertisement, blog image, website illustration, tutorial, and social media post follows this process.

The goal is consistency, scalability, and quality.

---

# Mission

Build the world's largest educational content library for collectors.

Every piece of content should:
- Educate
- Entertain
- Inspire
- Build trust
- Promote Collectiverse naturally

- Premium
- Studio quality

# Comic Standard

- Four panels preferred
- Maximum dialogue: 25 words per panel
- Visual storytelling first, text second
- Large expressions
- Simple backgrounds
- Easy to read on mobile

- Garage sales
- Flea markets
- Card shows
- Coin collecting
- Comics
- Pokémon
- Estate sales
- Marketplace
- Collectiverse features
- Holiday themes

### 3. Asset Library (Searchable Catalog)
- Atlas poses (indexed by emotion/action)
- Expressions
- Props
- Backgrounds
- Camera angles
- Lighting presets

### 4. Automated Production Checklist
Every piece of content follows the same checklist before publication, ensuring quality and brand consistency.
