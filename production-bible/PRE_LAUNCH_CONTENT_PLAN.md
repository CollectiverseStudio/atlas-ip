# Pre-Launch Content Production Plan — 30 Shorts + 30 Comics

## Overview

60 content pieces to build an Atlas content library before Collectiverse launches. This gives the platform an established media presence from day one. All content uses Atlas as the presenter/character and follows the brand bible.

**Production tool chain:** ChatGPT (scripts/prompts) → Veo/Runway/Kling (video) → Atlas Studio (Task 104, publishing)

## Production Notes

### For Shorts (Video Generation)
- Use Atlas character spec from `production-bible/ATLAS_CHARACTER_SPEC.md`
- Generate in Veo 3 / Runway Gen-4 / Kling 2.0
- Target: 9:16 aspect ratio, 15–60 seconds
- Must maintain Atlas visual consistency (use character lock prompt)
- Voiceover: upbeat, friendly, educational (ElevenLabs or native TTS)
- Captions: always (accessibility + silent autoplay)

### For Comics (Image Generation)
- 4–8 panels per comic
- Consistent panel layout (2×2, 2×3, or 2×4 grid)
- Atlas appears in every panel
- Speech bubbles with brand font
- Style: Pixar-quality 3D renders per panel (same as poses)
- Save as single image (all panels in one PNG, vertically stacked for mobile)

### Naming Convention
- Shorts: `atlas-short-{series}-{number}.mp4` (e.g., `atlas-short-tip-001.mp4`)
- Comics: `atlas-comic-strip-{number}.png` (continuing from existing 31, so start at 32)
- Thumbnails: `atlas-thumb-{content-id}.png`

### Publishing Flow
1. Content generated externally (ChatGPT + video/image AI tools)
2. Saved to `atlas-ip/` in appropriate folder
3. GitHub Action validates, resizes, syncs to collectiverse
4. Published via Atlas Studio (Task 104) with scheduling
5. Social media distribution (multi-platform)

## Seed Data for AtlasContent Table

All 60 items should be seeded as DRAFT in the AtlasContent model with:
- `contentId`: Atlas-{padded_number}-{slug}
- `title`: As listed above
- `category`: TIP, FINDS, INVESTIGATES, MARKETPLACE, REACTS, ADVENTURE
- `type`: SHORT or COMIC
- `status`: DRAFT
- `tags`: Relevant keywords
- `script`: Summary from this document

This gives Atlas Studio a backlog to work through.
