# Color Specifications

Official color palette files for Atlas in multiple formats.

## Expected Contents

- Pantone swatches (physical production)
- Adobe ASE files (design tools)
- CSS/SCSS variables export
- RGB/CMYK/HEX reference chart
- Material-specific color variants (glossy vs matte vs metallic)
- Print color proofs

## Quick Reference


| Color | Hex | Pantone (Approx) | Use |
|-------|-----|-------------------|-----|
| Helmet White | #FFFFFF | White | Helmet, armor, boots |
| Metallic Blue | #2F7DF6 | 2727 C | Accent panels, emblem, trim |
| Dark Graphite | #2C2F36 | Black 7 C | Visor, joints, hands |
| Silver | #C7CCD4 | 877 C | Ear discs, metallic details |
| Gold Star | #F5C542 | 7406 C | Star on head |
| Eye Green | #66FF99 | 353 C | Crescent eyes (glow) |
| Mouth Orange | #FF8C42 | 1505 C | Mouth |
