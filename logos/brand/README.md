# Brand Assets — Canonical Source

Brand logos and mascot images used by the Collectiverse app.

## Contents

| File | Purpose | Runtime Path in App |
|------|---------|---------------------|
| atlas-mascot.png | Atlas avatar/mascot | `/brand/atlas/atlas-mascot.png` |
| atlas-comic-strip.png | Atlas comic preview | `/brand/atlas/atlas-comic-strip.png` |
| collectiverse-logo.png | Platform logo | `/brand/collectiverse-logo.png` |

```
collectiverse/apps/web/public/brand/
├── atlas/

│   └── atlas-comic-strip.png
└── collectiverse-logo.png
```
