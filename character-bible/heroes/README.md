# Collectiverse Heroes

This folder contains the canonical hero-side character profiles for the Collectiverse universe.

## Characters

- `atlas.md` — Atlas, the Collectiverse Explorer
- `pixel.md` — Pixel, the Digital Scout
- `ink.md` — Ink, the Storykeeper
- `sterling.md` — Sterling, the Appraiser
- `forge.md` — Forge, the Protector and Preservation Specialist
- `porter.md` — Porter, the Logistics Guardian
- `echo.md` — Echo, the Provenance Signal

## Usage

Use these files as the source of truth for:

- AI image generation prompts
- Comic strip scripts
- Animation model sheets
- Mascot poses
- Merchandise design
- Licensing review
- Brand consistency
- Character dialogue
- Collectiverse product storytelling

No hero should be visually redesigned in a way that contradicts these profiles without formal approval from Collectiverse Studios.
