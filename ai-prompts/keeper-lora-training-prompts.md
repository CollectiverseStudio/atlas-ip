# Keeper LoRA Training — ChatGPT Prompt Packs

## How To Use This File

For each character:
1. Start a NEW ChatGPT session (fresh context)
2. Paste the **LOCK-IN PROMPT** — this establishes the character design
3. ChatGPT will generate the first image — confirm it looks right
4. Then paste each **POSE PROMPT** one at a time (1 per message)
5. Save each image as `{character}-{number}.png` (e.g. `pixel-01.png`)
6. After all 40, ZIP them and train the LoRA on Fal.ai

**IMPORTANT:** 
- All images should be on a **plain white background** (isolated character)
- All images should be **square** (1024x1024)
- Character should be **full body, centered**
- Same style across all 40: Pixar/DreamWorks CGI, chibi proportions
- NO text, NO other characters, NO complex backgrounds
