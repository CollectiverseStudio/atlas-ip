# Villain LoRA Training — ChatGPT Prompt Packs

## Same Process As Keepers:
1. Start a NEW ChatGPT session
2. Paste the LOCK-IN PROMPT
3. Generate 40 poses (one per message)
4. Save as `{character}-{number}.png`
5. ZIP + train LoRA on Fal.ai

**VILLAIN DESIGN RULES:**
- Same Pixar/DreamWorks CGI style as Keepers
- Darker palettes, sharper angles within rounded forms
- Red/black/dark replacing blue/white
- Corrupted versions of Keeper tech
- NOT scary — clever and threatening (Syndrome, Lotso, Doofenshmirtz energy)
- Badge: Corrupted/distorted (NOT the blue hexagon "C")
- Plain white background for all training images
